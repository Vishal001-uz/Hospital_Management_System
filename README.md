# MediQueue – Hospital Queue and Token Management System

MediQueue is a hospital queue management web application designed to organize patient registration, doctor management, and digital token-based consultations.

## Features

- Patient registration and patient record retrieval
- Doctor listing and management
- Digital token booking and token status tracking
- Patient, doctor, and administrator interfaces
- JWT-based authentication and role-based authorization
- QR code generation support
- Queue monitoring and status dashboards
- Analytics API for hospital queue information
- REST APIs documented using Swagger/OpenAPI

## Tech Stack

- Java 17
- Spring Boot
- Spring Security and JWT
- Spring Data JPA and Hibernate
- MySQL
- React.js and JavaScript
- Tailwind CSS
- Maven and Vite

## Project Architecture

The project contains a Spring Boot REST API backend and a React frontend. The backend uses a layered structure with controllers, services, repositories, and entities. The frontend also includes a localStorage-based mock service for frontend testing and demonstration.

## Purpose

The goal of MediQueue is to simplify hospital queue organization, improve visibility into token status, and provide a structured interface for patients, doctors, and administrators.
